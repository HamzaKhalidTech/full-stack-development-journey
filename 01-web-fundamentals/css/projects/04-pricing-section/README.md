# Pricing Section

A responsive and professional pricing section built with HTML and CSS.

## Project Overview

This project focuses on building a clean pricing section with multiple pricing plans.

The layout is designed to work across desktop, tablet, and mobile screen sizes.

## Features

- Three pricing plans
- Highlighted popular plan
- Responsive layout
- CSS Grid
- Flexbox
- Hover effects
- Smooth transitions
- Responsive typography
- Accessible button focus state
- Clean and reusable CSS structure

## Responsive Behavior

Desktop:

- Three pricing cards displayed in one row.

Tablet:

- Pricing cards adapt to a narrower layout.

Mobile:

- Pricing cards stack vertically for better readability.
