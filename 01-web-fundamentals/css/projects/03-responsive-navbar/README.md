# 03 - Responsive Navbar

A responsive navigation bar built with **HTML5** and **CSS3** as part of my full-stack development journey.

## 🎯 Project Goal

Build a clean, professional navigation system that adapts to different screen sizes:

- Desktop
- Tablet
- Mobile

## 🛠️ Technologies

- HTML5
- CSS3
- Flexbox
- Responsive Design
- Media Queries

## 📱 Responsive Behavior

### Desktop
- Horizontal navigation links
- Logo on the left
- Navigation links on the right
- Hamburger menu hidden

### Tablet
- Navigation spacing and typography adjusted
- Layout remains clean and readable

### Mobile
- Hamburger menu button displayed
- Navigation links hidden
- Layout optimized for smaller screens

> Note: The hamburger button is currently a visual UI element. JavaScript will be added later in the journey to make the mobile menu interactive.
