
# JavaScript Objects

This folder contains my JavaScript Objects learning journey, from basic object creation to modern object operations.

## 📚 Topics Covered

| # | File | Topics |
|---|---|---|
| 1 | `01-object-basics.js` | Object creation, keys and values |
| 2 | `02-properties-methods.js` | Dot notation, bracket notation, add, update and delete properties |
| 3 | `03-nested-objects.js` | Nested objects and accessing nested properties |
| 4 | `04-object-destructuring.js` | Destructuring, renaming variables and default values |
| 5 | `05-object-methods.js` | `Object.hasOwn()`, `Object.assign()`, `Object.freeze()` and `Object.seal()` |
| 6 | `06-this-keyword.js` | The `this` keyword in object methods |
| 7 | `07-object-keys-values-entries.js` | `Object.keys()`, `Object.values()` and `Object.entries()` |
| 8 | `08-spread-operator.js` | Object copying, combining objects and updating properties with spread syntax |

## 🎯 Learning Objectives

- Understand how JavaScript objects store data using key-value pairs.
- Access and modify object properties.
- Work with nested objects.
- Extract properties using destructuring.
- Use built-in object methods.
- Understand `this` in normal object method calls.
- Retrieve object keys, values and entries.
- Copy and combine objects using the spread operator.
- Understand the difference between shallow copies and deep copies.

## 💻 How to Run

Run any JavaScript file using Node.js:

```bash
node 01-object-basics.js
```

Replace the filename with the lesson you want to execute.
