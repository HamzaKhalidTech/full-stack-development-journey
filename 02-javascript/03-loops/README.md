# JavaScript Topic
# 03 - Loops

Loops are used in JavaScript to repeat a block of code multiple times.

They are an important part of programming because they help us avoid writing the same code again and again.

---

## Topics Covered

### 1. For Loop

File:

`01-for-loop.js`

The `for` loop is useful when we know how many times we want to repeat something.

Basic syntax:

```js
for (initialization; condition; update) {
    // code
}
