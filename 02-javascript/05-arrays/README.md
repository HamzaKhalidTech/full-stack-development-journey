# JavaScript Arrays
This folder covers JavaScript array fundamentals and commonly used array methods.

## Topics Covered

1. Array Basics
2. Array Methods
3. `push()` and `pop()`
4. `shift()` and `unshift()`
5. `slice()` and `splice()`
6. `map()`
7. `filter()`
8. `reduce()`
9. `find()`
10. `some()` and `every()`
11. `forEach()`
12. `sort()`
13. Array Destructuring

## Learning Objectives

- Create arrays and access elements using indexes.
- Add and remove array elements.
- Understand the difference between `slice()` and `splice()`.
- Transform arrays using `map()`.
- Filter elements using `filter()`.
- Calculate values using `reduce()`.
- Search arrays using `find()`.
- Test conditions using `some()` and `every()`.
- Iterate over arrays using `forEach()`.
- Sort numbers and strings.
- Extract array values using destructuring.
